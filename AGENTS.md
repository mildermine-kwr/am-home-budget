# Project Rules & Guidelines

## Automated Git Commit & Push Workflow
Every time you make any changes to files, add new features, fix bugs, or complete a task for the user:
1. **Stage all changes**: Run `git add .`
2. **Commit changes**: Run `git commit -m "<descriptive message in English or Thai reflecting the changes>"`
3. **Push to remote**: Run `git push origin <current-branch>` (e.g. `main`)
4. **Report to user**: Include the commit message and push status in the final response.
